# WellTrack AI — Intelligent Wellness Tracking Platform

## Overview

WellTrack AI is a modern AI-powered wellness and health tracking platform designed to help users monitor wellness activities, manage healthy habits, and receive intelligent AI-assisted insights through an interactive and responsive web application.

The project combines modern frontend technologies, AI integration, responsive UI design, and scalable React architecture to create a clean and engaging digital wellness experience.

This application was developed to strengthen practical skills in:
- React development
- TypeScript architecture
- AI integration
- Frontend engineering
- Component-based design
- Modern deployment workflows

# Motivation

The healthcare and wellness industry is increasingly moving toward personalized digital experiences. Many users struggle to consistently manage habits, sleep schedules, hydration tracking, and wellness routines in an organized and engaging way.

WellTrack AI was built as a smart wellness companion capable of:
- simplifying wellness tracking
- improving user engagement
- integrating AI-powered wellness assistance
- creating a scalable digital health platform

The project also serves as a practical implementation of modern frontend engineering concepts and AI-assisted applications.

# Installation Guide

## Clone Repository

```bash
git clone https://github.com/nandanavinothkumar-06/WellTrack-AI.git
```

---

## Navigate to Project Folder

```bash
cd WellTrack-AI
```

---

## Install Dependencies

```bash
npm install
```

---

## Start Development Server

```bash
npm run dev
```

---

## Open in Browser

```bash
http://localhost:5173
```

---

# Environment Variables

Create a `.env` file in the root directory:

```env
VITE_GEMINI_API_KEY=your_api_key_here
```
